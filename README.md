# Travel and Trips in Mauritania

A multilingual (English / French / Italian) website for a Mauritanian travel
company: Sahara expeditions, the iron ore train, the ancient cities of the
Adrar, and the Banc d'Arguin.

Static HTML, CSS and vanilla JavaScript — no framework, no build tooling to
install, nothing to pay for. It deploys anywhere that can serve files
(GitHub Pages, Netlify, any shared host).

---

## How it is put together

The 21 HTML pages at the top of the repository are **generated**. Never edit
them by hand — edit the sources in `src/` and run the build.

```
src/
  data/site.js          brand constants: phone, email, socials, domain
  data/photos.js        every photograph: chapter, focal point, captions ×3 languages
  data/images.json      generated by tools/process-images.py — do not edit
  content/en.js         all English copy
  content/fr.js         all French copy
  content/it.js         all Italian copy
  pages/*.js            page templates
  layout.js             <head>, navigation, footer, structured data
  build.js              renders everything

assets/
  css/main.css          the design system
  css/fonts.css         generated @font-face rules
  fonts/                self-hosted Cormorant Garamond + Inter (latin subsets)
  img/                  optimised WebP + JPEG fallbacks, and logo.svg
  js/app.js             all interactions

tools/
  process-images.py     turns original photos into responsive WebP sets
  shot.js, shots.js     dev helpers: screenshot pages with a headless browser
```

Output: `index.html`, `experiences.html`, `destinations.html`, `gallery.html`,
`about.html`, `travel-guide.html`, `contact.html` — in English at the root,
French under `/fr/`, Italian under `/it/` — plus `sitemap.xml`, `robots.txt`
and `404.html`.

## Building

```bash
npm run build       # or: node src/build.js
npm run serve       # preview at http://localhost:8099
```

The build refuses to finish if `fr.js` or `it.js` is missing a key that
`en.js` has, so the three languages can never silently drift apart.

## Common edits

**Change the WhatsApp number, email or socials**
`src/data/site.js` — one place, used by every button, link and booking
message on all 21 pages. Then `npm run build`.

**Change the domain used in canonical URLs / sitemap**
`src/data/site.js` → `domain`. It is currently
`https://travelandtripsinmauritania.com`. Note that `CNAME` in this
repository points at `maurimax.store` — set both to the domain you actually
publish on.

**Change any text**
`src/content/en.js` and its French and Italian twins. Prices, durations,
seasons and itineraries for the five experiences live there too.

**Add reviews**
`src/data/reviews.js`. Real reviews only: they are stored once and shown
verbatim in every language, never translated and never edited, because they
are someone else's words. The section is hidden while the list is empty.

**Blank fields are deliberate.** Durations, seasons, group sizes, highlights,
itineraries, the About page sections and the contact promises were removed
because nobody had confirmed them. Every one of those blocks disappears from
the site while empty and reappears as soon as it is filled in — so the site
never states something the company has not confirmed.

**Add new photographs**

1. Drop the originals in a folder, e.g. `~/new-photos/`.
2. Add each file to `CATALOG` in `tools/process-images.py`, mapping the file
   name to a short slug.
3. `python3 tools/process-images.py ~/new-photos`
4. Add the slug to `src/data/photos.js` with its chapter (`train`, `desert`,
   `culture`, `landscapes`, `travellers`), a focal point, and captions in the
   three languages.
5. `npm run build`

Images are emitted at up to four widths as WebP, plus a 1280px JPEG
fallback, and each one carries an inline blurred placeholder so nothing
flashes or shifts while loading.

## Booking

There is no payment system, by design. Every "Book this experience" button
opens WhatsApp with a message already written in the visitor's language,
naming the experience they were reading about. The contact form does the
same thing with the whole enquiry, and offers an email fallback.

## Notes

- Photography: every image on the site was taken on the company's own
  journeys. Nothing is stock.
- Accessibility: skip link, focus styles, keyboard-navigable lightbox,
  `prefers-reduced-motion` honoured throughout, and a `<noscript>` fallback
  so all content is readable with JavaScript disabled.
- SEO: per-page titles and descriptions in three languages, canonical URLs,
  `hreflang` alternates, Open Graph tags, `TravelAgency` and `FAQPage`
  structured data, and a generated sitemap.
